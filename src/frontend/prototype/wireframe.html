每个画面的区块清单

P-02找局 GET /match/parse
  • 信用分卡片：环形进度 + 完成次数 / 爽约次数 / 评价均分
  • 一句话找局：单行输入 + 4 个示例 chip，回车即搜
  • 条件筛选：项目横向 chips + 校区 + 水平 + 只看有空位
  • 推荐结果：卡片右上角匹配分，卡内"为什么推荐"标签
  • 最近活动：最多 6 条 + 悬浮发起按钮
P-04活动详情 GET /activities/{id}
  • 状态行：可报名 / 已满员 / 进行中 / 已结束 / 已取消
  • 事实卡：时间（本地时区）、地点、人数、费用、发起人信用分、说明
  • 身份相关操作区：发起人看到签到码与考勤，报名者看到签到与退报，其他人看到报名
  • 参与者名单：昵称、水平、信用分、签到状态、备注、主页入口
P-07签到 POST /activities/{id}/checkin
  • 两种方式并列：4 位签到码（主）/ 定位（次）
  • 失败态细分：403 码错或超范围（显示具体米数）、409 已签到
  • 成功态：换成结果页，给出活动摘要与下一步入口
