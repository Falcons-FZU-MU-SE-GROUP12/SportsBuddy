SportsBuddy · 前端交付总览

依据 sportmate后端.zip 里的《前端对接文档》实现：一个零安装、可离线运行的移动优先前端， 外加领域类图与可交互界面原型。三项交付物都可以直接在本地浏览器打开。

原型总览移动端原型（可跳转）12 屏展板页面结构与跳转类图

① 前端应用

原生 ES Module + 自研 200 行渲染内核，无需 npm install。 默认用内置离线数据，打开即可看；接真实后端只需改 index.html 里的一行配置。

→ 打开应用

  • 11 个页面 / 19 个接口全覆盖
  • 时区、错误码、权限差异都按文档处理
  • node tools/verify.mjs 自检 99 项

② 领域类图

从后端接口契约反推的 15 个类、20 条关系，附 Mermaid 源文件与离线渲染的 SVG。

→ 查看类图

  • docs/diagrams/class-diagram.mmd（可贴进 mermaid.live）
  • docs/diagrams/class-diagram.svg（可直接插进报告）

③ 界面原型

两种看法：单屏可跳转（像真机一样点着走）与 12 屏展板（一眼看全）。 都直接复用 frontend/src/pages 的页面模块，与前端代码同源。

→ 移动端原型（12 屏可跳转）
→ 12 屏展板 · 页面结构与跳转

  • mobile-prototype.html 是单文件：CSS/JS 全内联，双击即可打开，不用起服务
  • 按钮真会跳到对应屏；顶栏可切上一屏/下一屏、调出 12 屏目录、显示热区
  • 地址栏带 #p04 这样的 hash，可直接分享某一屏

怎么跑起来

  1. 在项目根目录执行 node tools/server.mjs（也可双击 start.cmd）
  2. 浏览器打开 http://127.0.0.1:5178/prototype/
  3. 接真实后端：把 frontend/index.html 里的 useMock 改为 false， apiBaseUrl 指向后端地址

不需要 npm install：本工程没有构建步骤，也没有 node_modules 依赖。

自检与再生成

node tools/verify.mjs99 项自检：接口、业务规则、页面渲染、时区
python tools/render-class-diagram.py由 .mmd 渲染出 SVG 类图
python tools/check-class-diagram.py几何校验：文字不溢出、连线不穿框
node tools/build-prototype.mjs重新生成本原型页
