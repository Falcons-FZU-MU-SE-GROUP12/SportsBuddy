### 本节点做了什么

本节点收掉 **P0 的 Issue #8「活动详情」**：P-04 详情页按「可报名 / 已结束 / 已取消 / 进行中」
四种状态接真实后端 `GET /activities/{id}` 验证，三条 AC 全部留了截图。

- **按 id 加载**：标题、时间、地点、人数、发起人信息块完整；不存在的 id 给错误提示 +「返回活动列表」。
- **参与者与状态可见**：参与者列表显示昵称 / 水平 / 信用分 / 状态标签（已报名、已签到、已到场、爽约）；
  满员 / 进行中 / 已取消 / 已结束四种状态联动正确（按钮置灰、红色取消提示、结束后出现「评价同场伙伴」）。
- **发起人管理入口**：发起人看到「你是发起人」+ 记录考勤 / 取消活动 + 4 位签到码；普通参与者一律看不到。

### 两个真问题

**① 参与者计数对不上。** 真实后端的 `participants` 保留 `cancelled` 记录（mock 不含），
取消报名后「参与者（N/容量）」会把已取消的人也算进去，与 `joined_count`、名额数字互相矛盾。
前端已过滤，并加断言锁定「计数不含已取消」；根因在 `converters.activity_detail`，已给后端建议。

**② 已结束的活动还显示「X 分钟后开始」。** `hero` 提示行无条件用相对时间，初版截图里
"已结束"徽标和"1 分钟后开始"同时出现。已按状态改写：结束→「已结束 · 时间段」、取消→「已取消」，
并加两条回归断言。
